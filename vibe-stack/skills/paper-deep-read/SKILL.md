# Paper Deep-Read

Beyond abstracts: full-text structured ingestion for Andy's research
curriculum. Companion knowledge: `self-improvement-research` topic.

## Workflow

1. **Fetch full text**: prefer the arXiv HTML version, fall back to the
   abstract page; note version and access level honestly.
2. **Extract**: core claim; method; key results with the authors' own
   numbers; stated limitations; unstated assumptions.
3. **Attack the evidence**: sample sizes, baselines, evaluation
   criteria, generalization risk. Ask: what would falsify this claim?
   Which alternative explanation fits the same data?
4. **Map to the stack**: name the exact mechanism, skill, rule, or
   artifact this upgrades. No mapping = say "interesting, not
   applicable yet" instead of forcing one.
5. **Deliver**: structured notes (canvas if Andy will keep them),
   claims tied to fetched text only — never fabricated quotes or
   invented section references. End with one open question.

## Rules

- Report the authors' numbers AS their measurements, not as
  established reality; label the epistemic status.
- If only abstract-level access was achieved, say so — abstract-level
  conclusions are weaker and marked as such.
- A deep read should end with either an installed upgrade or a
  recorded reason none applies.
